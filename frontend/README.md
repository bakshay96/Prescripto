# Prescripto Frontend - Web Application

A modern, glassmorphic single-page interface for doctors and pharmacists.

## Features
1. **Doctor Dashboard**:
   - Patient Registration with **Dynamic Real-Time Age Calculation**.
   - Patient search by name or village location.
   - Interactive Prescription Builder (Multi-medicine row selection).
   - Prescriptions History & status tracking.

2. **Pharmacist Dashboard**:
   - Real-time Medical Store Inventory management.
   - Low stock alerts (⚠️ Stock <= Min threshold) & Expired badges.
   - Quick Restock modal dialogs.
   - Live Prescription Dispense Queue with instant stock deduction feedback.

## Running Locally
Double-click `index.html` or serve with any static web server:
```bash
npx serve .
```
or python:
```bash
python -m http.server 3000
```
